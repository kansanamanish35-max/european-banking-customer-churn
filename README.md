# 🏦 Customer Segmentation & Churn Pattern Analytics in European Banking

## 📌 Internship Project

An end-to-end Data Science and Business Analytics project focused on analyzing customer churn patterns, identifying high-risk customer segments, and developing an interactive Streamlit dashboard for the European banking sector.

---

---

## 🎯 Project Objective

The main objective of this project is to analyze customer churn behavior and identify customer segments that are more likely to leave the bank.

The project focuses on:

- Customer churn analysis
- Customer segmentation
- Geographic risk analysis
- Demographic analysis
- Financial profile analysis
- Customer engagement analysis
- High-value customer identification
- Rule-based churn risk scoring
- Interactive dashboard development

---

## ❓ Research Questions

1. Which customer groups have the highest churn rates?
2. How does churn differ across France, Germany, and Spain?
3. How does age influence customer churn?
4. Does customer activity affect churn?
5. How do credit score, tenure, balance, and product usage relate to churn?
6. Are high-value customers more likely to churn?
7. Which combined customer segments should receive retention attention?

---

## 📊 Dataset

The dataset contains:

- **10,000 customer records**
- **14 variables**
- Target variable: `Exited`

### Important Variables

| Variable | Description |
|---|---|
| CreditScore | Customer credit score |
| Geography | Customer country |
| Gender | Customer gender |
| Age | Customer age |
| Tenure | Years with the bank |
| Balance | Account balance |
| NumOfProducts | Number of bank products |
| HasCrCard | Credit card ownership |
| IsActiveMember | Customer activity status |
| EstimatedSalary | Estimated salary |
| Exited | Customer churn indicator |
